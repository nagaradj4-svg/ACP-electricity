🐙 GitHub Backup / Restore

Back up all data as JSON to a GitHub repository file, and restore it on any device. Requires a personal access token with repo write access — kept only in this browser's local storage.

📗 Google Sheets Sync (via Apps Script)

Paste the URL of a deployed Google Apps Script Web App to push data to a connected Google Sheet. See instructions below.

How to set up the Apps Script Web App
  1. Open your Google Sheet → Extensions → Apps Script.
  2. Paste a script that reads e.postData.contents as JSON and writes rows to sheets named "Connections" and "Demands".
  3. Deploy → New deployment → Web app → Execute as "Me" → Who has access "Anyone".
  4. Copy the deployment URL into the field above.
